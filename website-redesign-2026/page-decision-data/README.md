# Page decision data — for the keep/kill/consolidate review

**What this is.** One row for every English page in the review sheet (2,022 pages across the seven sites), with signals that help a stakeholder decide keep, kill, or consolidate. Built September 2, 2026 by reading every page once, plus the August 26 audit data. Merge into the review sheet by the "Web address" column.

**The sheet has 2,027 rows; this file has 2,022.** Five sheet rows were added by hand and are not in the site's own page lists; they simply won't match and can be left as-is.

## Columns

| Column | What it means | Coverage |
|---|---|---|
| Web address, Site | The page and which site it belongs to | all |
| Loads OK | yes / redirects / error 404 / no response | all |
| Redirects to | Where the page now sends visitors, if it moved | all |
| Hidden from Google | "yes" means the page asks search engines not to list it | all |
| Word count | Words of readable content (before scripts run — see caveats) | all |
| Content amount | ok / thin (under 250 words) / very thin (under 100) / loads by script / gated resource | all |
| Other pages linking to it | How many other pages on the network link here from their content. 0 = nothing points to it | all |
| In site menu | "yes" = reachable from the site-wide menu or footer | all |
| Links to broken pages | How many links on this page point to dead pages | all |
| Nearly identical to / Similarity | Its closest twin when 70%+ of the readable content matches | all |
| Likely required (legal/compliance) | Flagged by name: legal notices, policies, board materials, privacy, ADA. Don't kill these on traffic grounds | all |
| On enrollment, donation, or careers path | Part of the money path — "fix," never "kill" | all |
| Mobile speed score / Page size MB | From the August 26 audit | 57 pages only |
| What the data suggests | Filled only where the evidence is mechanical (dead, moved, duplicate, or empty-and-orphaned). Blank means the data doesn't point anywhere — the decision is the stakeholder's | 460 rows |

## Headlines from the data

- **57 dead pages** are listed in the sites' own public page lists (56 on the Curriculum Hub, 1 on NYC).
- **123 near-duplicate pages**, including live leftover clones of key pages on the main site (`/homepage-2/`, `/support-fund/` = donate, `/uncommon-sense-faq/` = the FAQ) and identical legal pages repeated across sites.
- **258 pages with almost no content and no links pointing to them** — invisible to any visitor who doesn't type the address.
- **25 pages flagged likely-required** and **127 on the money path** — pre-sorted so stakeholders don't waste review time on them.

## Caveats — read before judging a page by this file

1. **Word counts are from the page as delivered.** Pages that build their content with scripts after loading show fewer words than a visitor sees. Most pages are fine; news posts undercount somewhat.
2. **Main-site people pages (115) can't be read this way** — every one serves the same generic "Our People" text; the person's bio never arrives in the page itself. Marked "loads by script." Do not judge their content from this file.
3. **Curriculum Hub resource pages (931) are sign-in gated** — they look empty and unlinked here because the library that lists them runs on scripts and the downloads require an account. Marked "gated resource." A Hub owner has to make those calls; this file can only say which ones are dead (56 are).
4. **"Other pages linking to it" counts links written into page content**, not menu/footer links (those are counted separately in "In site menu") and not links generated by scripts.

## What's missing, and where it comes from

- **Visitor numbers and drop-off (GA4):** only someone with the Google Analytics login can export these. When the two-year export arrives, it joins this file by web address. Camden has no analytics installed, so Camden visitor data does not exist anywhere.
- **Google Search performance:** same situation — exported from Google Search Console by someone with access. Best available signal for "kill it and nobody will notice."
- The March writer audit's page-quality calls for ~23 main-site pages are already reflected in the review sheet's audit notes and were not duplicated here.
