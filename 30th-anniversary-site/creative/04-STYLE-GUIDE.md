## Typography

### Headline Font: Knockout (Primary)
Knockout is the primary typeface for the Uncommon brand — bold, condensed, with authority.

| Weight | Usage on This Page |
|---|---|
| **Knockout 49** (Liteweight) | Primary headlines, section titles, hero statement, key statistics |
| **Knockout 48** | Secondary headlines, longer headline lines that need more horizontal space |
| **Knockout 29** | Department labels, short supporting text, subheadings up to 3 paragraphs |

**Leading formula for headlines:** Point size × 0.9 = Leading

**Case rules:**
- **All caps** — for short copy lines, buttons, labels, and headlines of 6 words or fewer
- **Sentence case or title case** — for longer headlines and full statements

**Do not use Knockout for body copy.** It is a display font only.

---

### Body Font: Libre Franklin (Secondary)
Available free via Google Fonts. Clean, readable, suitable for all long-form paragraph text.

| Weight | Usage |
|---|---|
| **Regular** | All body copy, paragraph text |
| **Bold** | Inline emphasis, callout text |
| **Italic** | Pull quotes, supporting details |
| **Bold Italic** | Strong emphasis within body |

**Leading formula for body text:** Point size × 1.25 = Leading

**Recommended body sizes:**

| Context | Point Size | Leading |
|---|---|---|
| Small caption / label | 12pt | 15pt |
| Standard body | 16pt | 20pt |
| Large body / intro text | 22pt | 27.5pt |
| Feature/display paragraph | 31pt | 38.75pt |

**Column width:** Optimal 4–9 words per line. Avoid hyphenation. Use single-line composer for ragged right text.

## Color System

### Primary Palette

| Name | HEX | RGB | Usage |
|---|---|---|---|
| **Uncommon Navy** | `#1034B4` | 16, 52, 180 | Hero, section anchors, backgrounds with weight, nav |
| **Uncommon Yellow** | `#FFB500` | 255, 181, 0 | Anniversary mark, statistics callouts, accents, logo bars |
| **Black** | `#000000` | 0, 0, 0 | Body text, dividers, high-contrast elements |
| **White** | `#FFFFFF` | 255, 255, 255 | Default background, photo sections, breathing room |

**Accessibility rule:** Uncommon Yellow is NOT accessible at small scales. Only use Yellow for the logo, the anniversary mark, or text **above 19pt**. For all text below 19pt, use Navy or Black.

**Background rule:** Only primary colors (Navy, Yellow, Black, White) may be used as section backgrounds. White is the default when full-color photography is present.

## Logo Usage on This Page

- **30th Anniversary mark:** Primary color version (navy + gold) throughout. Gold Glitter variant in hero or closing section only — once, as a milestone punctuation.
- **Lockup:** Always use an approved horizontal or vertical lockup — anniversary mark never appears without the Uncommon Schools logo
- **Hierarchy:** Uncommon Schools logo is always primary. Anniversary mark is always secondary.
- **Logo bars:** The horizontal rule system from the Uncommon logo should extend across section headers as structural dividers

---

## Spacing & Grid

- Desktop: 12-column grid, generous gutters
- Section padding: 80–120px top/bottom for major sections
- Mobile: Single column, reduced padding (40–60px)
- The larger the headline, the wider the column — Knockout at display size needs room to breathe

## Component Notes

### Section Dividers
Use the Uncommon logo bar system — a thin yellow or navy rule — as the recurring visual connector between sections. Mirrors the logo's horizontal rule structure.

### Statistics / Impact Numbers
- Knockout 49, all caps, large scale (60pt+)
- Yellow for the number, white or black for the label depending on background
- Each stat is a standalone moment — not a list, not a table

### Testimonial / Pull Quote
- Libre Franklin Italic, display size (22–31pt)
- Left-aligned with a navy or yellow vertical rule as a quote marker
- Student name and school in Libre Franklin Bold, small scale

### Buttons / CTAs
- Knockout 49, all caps, 6 words or fewer
- Primary CTA: Navy background, white text
- Secondary CTA: Yellow background, navy text
- No rounded corners — clean, direct, on-brand

### Photography Treatment
- Full-bleed where used — no small inset images
- Authentic student photography: candid, in-context, warm tones
- Dark overlay when logo or text sits over photography — sufficient contrast required (check via webaim.org)
- Archival / historical photography: consistent treatment TBD — may use slight desaturation or sepia-to-color treatment to indicate "then vs. now"
