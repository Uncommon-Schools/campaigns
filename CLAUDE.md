# campaigns

Campaign projects and audits for Uncommon Schools, one folder per project. Each project's working state lives in its own folder. This file only tells an agent where to start.

Projects:

- `website-redesign-2026/`: the rebuild of uncommonschools.org and its five regional sites with the agency Spinutech. Runs on the record-file system below since 2026-11-02.
- `30th-anniversary-site/`: early planning files for the 30 Years of Impact page (brief, task tracker, decision log, team briefs, assets). The page's code lives in the separate repo `uncommon-30th-anniversary-website`, which has its own `PROJECT.md`.
- `sy27-28-enrollment-messaging/`: the SY27/28 enrollment messaging work (headlines, the marketing team's source deck, meetings). It informs the redesign's content and is not part of it.
- `presentations/`: decks (`ai-showcase-2026`, `et-website-redesign`).

## If you are an agent starting here

The message that started your session names your role and the project folder you work in. Read these, in this order, before you do anything else:

1. `<project>/INSTRUCTIONS.md`: the operating instructions. Follow them; do not just read them.
2. `<project>/HANDOFF.md`: where things stand and the next step.
3. `<project>/decisions.md`: what has been decided and why.
4. `<project>/log.md`: every approved piece of work, with what is needed to find it again.

Then run the start-of-session steps in the instructions, tell Anthony where things stand in three short lines, and wait for his go.

Today only `website-redesign-2026/` has these files. If your message sends you to a folder that does not have them, say so to Anthony and do nothing else.
